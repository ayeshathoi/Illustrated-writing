      Comments

      Readers can leave anonymous comments on your stories and public journal entries. Comments are saved in a Google Sheet that only you control.

      How to set up comments (5 minutes, one time)
      1. Open sheets.new and name the sheet Story comments.
      2. In the menu choose Extensions → Apps Script.
      3. Delete what's there and paste everything from the file comments/google-apps-script.js in your project folder. Click Save.
      4. Click Deploy → New deployment, click the gear and choose Web app. Set Execute as: Me and Who has access: Anyone, then Deploy and allow access.
      5. Copy the Web app URL (it ends in /exec), paste it above, save, then commit and push.

      To remove a comment, delete its row in the sheet, or type anything in its hidden column.
